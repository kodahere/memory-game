# Memory Game

Классическая игра на память с чемпионами League of Legends.

## О проекте

16 карточек (8 пар) с чемпионами LoL. Цель — найти все пары за минимальное число ходов.
Результаты сохраняются в localStorage, топ-10 отображается в таблице лидеров.

## Технологии

- Vanilla JavaScript (ES-модули)
- CSS Grid
- localStorage

## Как играть

1. Клик по карточке - она переворачивается.
2. Клик по второй - если пара совпала, обе остаются открытыми.
3. Если не совпали - закроются через секунду.
4. Найдите все 8 пар. Итог - количество ходов.
